# render-elouais-dolls
A script that downloads in gifs and resizes elouais dolls from the archive website

Open Command Prompt as Administrator, then run:

python -m ensurepip --upgrade
python -m pip install --upgrade pip setuptools wheel
pip install pillow requests

Clone the repo to your pc
git clone https://github.com/Alejandraj0rge/render-elouais-dolls.git

Replace the links with the links to your doll elements in the script and in the animated_layers just put the ones that you want to move. 

Go to the folder where your script is downloaded:
run 
python make_doll.py

It'll return the doll gif downloaded.
